## 3️⃣ ASSUMPTIVE CLOSE SYSTEM (THE CORE OF SMARTSEND SELLING)

Roofers hate being asked "Do you want it?"

You never ask that.

All closes are assumptive.

### Close Script #1 — Card Decision

> "Cool — which card do you want to start with? Business or personal?"

**How this helps roofers:**

Roofers respond fast to binary choices.

This removes indecision and gets them activated ASAP.

### Close Script #2 — Soft Push

> "Let's go with Growth — it's what 90% of roofers start with.
>
> What name should I put on your account?"

**How this helps roofers:**

You're not selling them something — you're guiding them into the correct plan.

### Close Script #3 — Tonality Close

Your tone should be casual, confident, no pressure:

> "Alright, let's get this live so you can see leads rolling in."

**How this helps roofers:**

They feel like this is normal, easy, and everyone is doing it.

Roofers follow confidence.
