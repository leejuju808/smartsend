### SOP: Daily Operator (SmartSend On-Duty)

**Owner outcome:** SmartSend keeps creating demand and converting it into booked jobs even if someone quits.

#### Role: SmartSend On‑Duty Operator

- **Primary**: the person responsible for clearing the Daily Operator Queue.
- **Backup**: takes over automatically if the primary is missing.

This is a **role**, not a tool.

#### Daily (required)

- **Open SmartSend → Daily Operator Queue**
- **Clear in order**:
  - **Homeowners waiting** (threads needing reply)
  - **Stalled estimates** (money at risk)
  - **Follow-ups due today** (FYI; system sends automatically)
- **Confirm**:
  - Outreach is running (no manual pause)
  - No critical delivery issues blocking sending

#### Completion definition

You are done when:

- No “needs reply” threads remain unhandled.
- No stalled estimate items are ignored.
- Follow-ups remain enabled and active.
