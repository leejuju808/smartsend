### SmartSend SOPs (Institutional)

These SOPs assume SmartSend is the operating system.

- `SMARTSEND_POLICY.md`: policy-level rules (not optional).
- `DAILY_OPERATOR_SOP.md`: who runs SmartSend today + daily workflow.
- `JOB_LOGGING_SOP.md`: jobs must be logged; if it’s not logged, it didn’t happen.
