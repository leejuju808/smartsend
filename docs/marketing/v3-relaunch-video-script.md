## Visual Requirements

### Color Palette
- Primary: Black (#000000)
- Accent: Amber/Gold (#F59E0B)
- Text: White (#FFFFFF)
- Secondary: Gray (#6B7280)

### Typography
- Bold, modern sans-serif
- Large, readable text
- High contrast for dark background

### Motion Graphics
- Smooth transitions (fade, slide)
- Lightning bolt animation (subtle)
- Dashboard animations (realistic)

---

## Production Notes

### Recording Specifications
- Resolution: 1080p minimum (4K preferred)
- Frame rate: 30fps
- Aspect ratio: 16:9 (landscape) or 9:16 (vertical for social)
- Duration: 30-45 seconds
- Audio: Clear voiceover, subtle background music

### Screen Recording Tips
- Use real data (anonymized if needed)
- Show actual product functionality
- Smooth cursor movements
- Highlight key features clearly

### Post-Production
- Add subtle background music (tech/electronic)
- Include sound effects for UI interactions (optional)
- Add Product Hunt logo/badge overlay
- Include closed captions/subtitles
