# Block 19740 — Screenshot Specifications

**Purpose**: Detailed specifications for creating marketing-grade screenshots of the SmartSend Owner Inbox.

---

## General Requirements

### Resolution
- **Desktop**: 1920x1080 (Full HD) minimum
- **Mobile**: 1080x1920 (portrait) or 1920x1080 (landscape)
- **Export format**: PNG (lossless) or JPG (high quality, 90%+)

### Browser
- **Recommended**: Chrome or Firefox (best rendering)
- **Version**: Latest stable version
- **Zoom**: 100% (no browser zoom)

### Data
- **Use sample data** — No real customer information
- **Realistic names** — "Sarah M.", "John D.", "Mike R."
- **Realistic emails** — "sarah.m@example.com"
- **Roofing context** — Leaks, estimates, insurance claims
- **Clean data** — No placeholder text, no errors

### UI State
- **Polished UI** — No bugs, no glitches
- **Consistent colors** — Same color scheme throughout
- **No overlays** — Close modals, tooltips, dropdowns before screenshot
- **Clean state** — No error messages, no loading spinners
