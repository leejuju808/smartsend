## Production Notes

### Visual Requirements
- **Resolution**: 1920x1080 (Full HD)
- **Frame Rate**: 30fps minimum
- **Color**: Clean, professional, roofing industry colors
- **Animations**: Smooth, not jarring
- **Text Overlays**: Clean font, readable, not distracting

### Voiceover Requirements
- **Tone**: Professional, confident, roofing-focused
- **Pace**: Fast but clear (not rushed)
- **Voice**: Male or female, clear pronunciation
- **Background Music**: Subtle, professional (optional)

### Screen Recording Tips
- Use clean sample data (no real customer info)
- Ensure UI is polished (no bugs, no placeholder text)
- Record in Chrome/Firefox (best rendering)
- Use screen recording tool (Loom, OBS, QuickTime)
- Record at native resolution, scale down if needed

### Editing Tips
- Keep cuts fast (2-3 seconds per shot)
- Smooth transitions between actions
- Highlight important UI elements (zoom, highlight box)
- Add subtle animations to text overlays
- End with clear CTA or tagline
