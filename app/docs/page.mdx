# SmartSend AI ⚡ — Cold Email OS

End-to-end cold outreach: **Import → Schedule/Send → Queue (Retry/Cancel) → Auto-Reply Detection → Dashboard + Billing.**

<a id="stack" />

## Stack

- **Frontend**: Next.js (App Router) + Tailwind + shadcn/ui  
- **Backend**: Supabase (Postgres, Auth, RLS, Edge Functions)  
- **Billing**: Stripe (Checkout + Billing Portal)  
- **AI**: OpenAI (reply classification)  
- **Integrations**: Postmark / Gmail / Outlook webhooks (Zapier/Make or native)  

<a id="features" />

## Key Features

- CSV Lead Importer (mapping, Zod validation, dedupe, downloadable **error CSV**)
- Send Queue with **Bulk Retry**, **Cancel**, filters + **CSV export**
- **Auto-Reply Detection** → marks lead `replied`, logs event, cancels future steps
- Logs Drawer + Row Actions (View Logs / Copy Error / Retry / Cancel)
- **Billing gates**: Starter (1 campaign, 2k rows/import), Pro (configurable)
- UX polish: status pills, attempt chip, skeletons, empty states

<a id="reply-detection" />

Reply Detection (Webhook → Edge Function)

POST JSON:

```json
{
  "provider": "postmark|gmail|outlook|sendgrid|mailgun",
  "thread_id": "provider-thread-id",
  "message_id": "message-id",
  "subject": "Re: ...",
  "body": "Plain text body",
  "from_email": "prospect@company.com",
  "to_email": "you@smartsend.ai"
}
```

The function classifies with OpenAI; if human reply → set leads.status='replied', log lead_replied, cancel queued steps.

Security: Must include header X-Reply-Secret: <REPLY_WEBHOOK_SECRET>.

<a id="security" />

Security Notes

Edge Function requires X-Reply-Secret

Keep Service Role key server-only

Use RLS on leads, send_queue, campaigns, campaign_logs

<a id="troubleshooting" />

Troubleshooting

Reply not matching: ensure you store provider thread_id on send (falls back to from_email)

401 on webhook: secret header missing/incorrect

Stripe webhook: run stripe listen locally and set STRIPE_WEBHOOK_SECRET

Import issues: check downloadable error CSV
