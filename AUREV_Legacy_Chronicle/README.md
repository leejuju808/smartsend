# AUREV Legacy Chronicle (2025 → 2035)

## Overview
A 4-minute corporate-cinematic script for AUREV's founder's film. Black-and-gold aesthetic, narrated in the style of Apple "Think Different" meets SpaceX vision reel.

## Production Specifications

### Visual
- **Aspect Ratio**: 21:9 ultra-wide
- **Color Palette**: 
  - Black: #0A0A0A
  - Gold: #F8C948
  - Accent: #EAEAEA
- **Typography**: 
  - Titles: Poppins Bold
  - Body: Inter Regular
- **Motion**: Slow-fade transitions, lightning particle streaks, world-map orbit sequences

### Audio
- **Style**: Hybrid orchestral → ambient synth → silence close
- **Voice-over**: Clean, professional, visionary tone
- **Sound Design**: Minimal, atmospheric, supports narrative arc

### Duration
- **Total Runtime**: 3 minutes 45 seconds
