# Storyboard Frame 02: GENESIS (2025-2026)

## Visual Composition
- **Layout**: Split-screen showing three dashboard interfaces
- **Background**: Dark gradient from black to deep charcoal
- **Foreground**: Three glowing dashboard panels (SmartSend, OpsGrid, Agent Cloud)
- **Camera**: Tracking shot moving left to right across dashboards, then wide pull-back

## Animation Sequence
1. **0:10-0:18**: Three separate dashboards illuminate sequentially
   - **SmartSend** (left): Cold email sequences light up in gold
     - Email chains animate, connections form between nodes
     - Send metrics rise (0 → 10K → 100K)
   
   - **OpsGrid** (center): Operations brain visualizes
     - Process flows illuminate, decision trees branch
     - Efficiency metrics spike (45% → 92%)
   
   - **Agent Cloud** (right): Intelligence hands activate
     - Agents spawn as gold particles, form clusters
     - Activity streams cascade like rain

2. **0:18-0:22**: Three orbits appear, representing each system
   - Each orbit is a glowing gold ring
   - Orbits begin to converge toward center
   - Collision creates glowing nucleus

3. **0:22-0:26**: Nucleus expands, forms AUREV HQ logo
   - Logo pulses with unified rhythm
   - Gold light radiates outward in waves

## Typography
- **Overlay Text** (appears at 0:24): "Execution at the Speed of Thought"
- Font: Poppins Bold
- Color: #F8C948
- Position: Centered, lower third
- Animation: Fade in, slight scale-up (1.0 → 1.1)

## Color Palette
- Primary: #0A0A0A (black), #1A1A1A (charcoal gradient)
- Accent: #F8C948 (gold - all UI elements)
- Secondary: #EAEAEA (accent text/metrics)
- Dashboard panels: Semi-transparent gold overlay (20% opacity)

## Sound Design Notes
- Mechanical whir building to orchestral swell
- Each system adds layer: email (percussive), ops (strings), agents (synth)
- Unified crescendo as orbits collide

## Duration
16 seconds
