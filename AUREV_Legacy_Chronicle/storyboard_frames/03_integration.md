# Storyboard Frame 03: INTEGRATION ERA (2026-2027)

## Visual Composition
- **Layout**: Grid of synchronized dashboard panels
- **Background**: World map silhouette (dark blue-gray)
- **Foreground**: Multiple dashboard interfaces, metrics visualizations
- **Camera**: Orbital rotation around dashboard cluster, then zoom into world map

## Animation Sequence
1. **0:26-0:32**: Dashboard panels align in perfect symmetry
   - Panels slide into grid formation
   - Metrics synchronize across all panels
   - Charts and graphs animate in harmony
   - Numbers rise in unified rhythm

2. **0:32-0:38**: Gold threads emerge from dashboards
   - Threads connect between panels
   - Threads extend beyond frame boundaries
   - Threads weave across continents on world map
   - Network pattern forms across globe

3. **0:38-0:42**: AUREV HQ logo pulses at center of network
   - Logo sits at intersection of all threads
   - Each pulse sends ripple through network
   - Threads pulse in response, creating wave effect

4. **0:42-0:44**: Caption overlay appears
   - "When systems began to learn — not wait."
   - Fade in from bottom

## Typography
- **Metrics**: Inter Regular, #EAEAEA
- **Caption**: Poppins Bold, #F8C948
- Position: Lower third, centered

## Color Palette
- Primary: #0A0A0A (background)
- Map: #1A2A3A (dark blue-gray)
- Threads: #F8C948 (gold)
- Dashboard panels: Semi-transparent gold (#F8C948 at 15% opacity)
- Metrics: #EAEAEA (light gray)

## Sound Design Notes
- Data streams: High-frequency chimes (8-bit style)
- Orchestral strings building tension
- Low synth bass for world map reveal
- Ambient pad sustains throughout
