# Audio Directory

## Purpose
This directory contains all audio assets for the AUREV Legacy Chronicle video.

## Files

### voiceover.wav
- **Format**: WAV, 48kHz, 24-bit, Mono
- **Duration**: 3 minutes 45 seconds
- **Content**: Complete voice-over narration for the entire script
- **Style**: Clean, professional male/female voice (founder's tone)
- **Reference**: Apple "Think Different" meets SpaceX vision reel aesthetic
