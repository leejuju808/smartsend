## 🎨 Asset Requirements

### Logos

**Primary Logo:**
- Format: SVG (vector) + PNG (raster)
- Sizes: 200x80 (header), 400x160 (hero), 800x320 (print)
- Colors: Gold (#EAB308) on black background
- Variants: Dark mode (gold on black), light mode (black on white)

**Icon Only:**
- Format: SVG + PNG
- Sizes: 64x64, 128x128, 256x256, 512x512
- Usage: Favicons, app icons, social avatars

**Favicon:**
- Formats: ICO, PNG
- Sizes: 16x16, 32x32, 48x48

### Screenshots

All screenshots should be:
- Resolution: 1920x1080 minimum
- Format: PNG with transparency
- Background: Black (#000000) or dark gray (#1F2937)
- Highlight: Gold accents on interactive elements
- Watermark: Optional, small AUREV logo corner

**Dashboard Full:**
- Shows unified metrics across SmartSend, OpsGrid, Agent Cloud
- Active orgs, MRR, ARR, daily actions
- Real-time activity feed

**SmartSend Inbox:**
- Unified inbox with AI replies
- Thread view with tone detection
- Pause/resume campaign buttons

**OpsGrid Workflows:**
- Workflow builder interface
- Drag-and-drop automation
- Contact management view

**Agent Cloud Deploy:**
- Marketplace of agents
- Deployment interface
- Running agents dashboard

**Unified Metrics:**
- Cross-app analytics
- Revenue breakdown by app
- Usage tracking visualization

### Photos

**Founder Headshot:**
- Format: JPG
- Resolution: 2000x2000 minimum
- Background: Professional, neutral
- Style: Clean, modern, confident
- Usage: Press articles, about page, social

### Video

**Founder Intro (60 seconds):**
- Format: MP4, MOV
- Resolution: 1080p minimum
- Aspect: 16:9
- Content: Julian introduces AUREV HQ, vision, traction
- Style: Direct-to-camera, professional

**Product Demo (2-3 minutes):**
- Format: MP4
- Resolution: 1080p
- Screen recording + voiceover
- Highlights: Dashboard, SmartSend, OpsGrid, Agent Cloud
- CTA: Try AUREV HQ free

**Lightning Animation (5 seconds):**
- Format: MP4, GIF
- Resolution: 1920x1080
- Content: Gold lightning bolt streaks across black
- Usage: Video intro, social posts

**YouTube Shorts (3-5 clips):**
- Format: MP4
- Resolution: 1080x1920 (vertical)
- Duration: 15-60 seconds each
- Content: Quick product highlights, founder quotes, metrics

### Documents

**Media Sheet:**
- Format: PDF + Markdown source
- Pages: 1 page
- Content: Stats, facts, quotes, contact info
- Style: Clean, professional, easy to scan

**Brand Guidelines:**
- Format: PDF + Markdown source
- Pages: 5-10 pages
- Content: Logo usage, colors, typography, tone
- Style: Visual, examples, dos and don'ts

**Investor Deck:**
- Format: PDF
- Pages: 7 slides
- Content: Problem, solution, traction, vision
- Style: Data-driven, professional
