## Video Best Practices

1. **Keep it short:** Focus on key features and benefits
2. **High quality:** Use screen recording tools (Loom, OBS, or similar)
3. **Brand consistency:** Include SmartSend logo/branding
4. **Call to action:** End with link to demo or signup
5. **Optimize:** Compress for web while maintaining quality

## Upload Instructions

1. Export video in MP4 format
2. Optimize file size (use tools like HandBrake or ffmpeg)
3. Place final video as `smartsend-demo.mp4` in this directory
4. Update `/press` page if video location changes
