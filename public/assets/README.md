# SmartSend AI Press & Media Assets

This directory contains downloadable assets for press, media, and investors.

- **Description:** SmartSend AI brand logos in multiple formats (PNG, SVG, EPS)
- **Includes:**
  - Full logo (horizontal)
  - Icon/wordmark variations
  - Light and dark versions
  - High-resolution versions for print

### 🖼️ screenshot-dashboard.png
- **Description:** High-quality screenshot of the SmartSend dashboard
- **Recommended:** 1920x1080 or higher resolution
- **Status:** ⚠️ Placeholder - Add actual dashboard screenshot

### 📄 press-release.pdf
- **Description:** Official press release in PDF format
- **Content:** Available in `press-release.txt` - convert to PDF
- **Status:** ⚠️ Convert `press-release.txt` to PDF format

### 📊 investor-deck.pdf
- **Description:** 7-slide investor deck (Q1 2025)
- **Structure:** See `investor-deck-structure.md` for slide-by-slide guide
- **Creation:** Build in Canva or Pitch, then export as PDF
- **Status:** ⚠️ Create using `investor-deck-structure.md` as reference

## Notes

1. All assets should be optimized for web (except print-ready logos)
2. Maintain consistent branding across all materials
3. Update assets quarterly or when major features launch
4. Ensure all screenshots are current and reflect latest UI

## Adding Assets

1. Place logo ZIP file as `smartsend-logo.zip`
2. Add dashboard screenshot as `screenshot-dashboard.png`
3. Convert `press-release.txt` to PDF
4. Create investor deck from structure document and export as PDF
